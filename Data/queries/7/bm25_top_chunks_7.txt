file named foo.js : const circle = require ( './circle.js' ) ; console . log (

the first line, foo.js loads the module circle.js that is in the same directory
as foo.js . Here are the contents of circle.js : const { PI } = Math ; exports .
area = ( r ) => PI * r ** 2 ; exports . circumference = ( r ) => 2 * PI * r ; js
copy The module circle.js has exported the functions area() and circumference()
. Functions and objects are added to the root of a module by specifying
additional properties on the special exports object. Variables local to the
module will be private, because the module is wrapped in a function by Node.js
