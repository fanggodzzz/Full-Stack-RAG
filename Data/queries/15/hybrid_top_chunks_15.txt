customizable to a certain degree). We have to map the appropriate extensions to
the appropriate media types. In this example, we map .html to the media type
text/html and we map .atom to application/atom+xml. This will make sure the
appropriate views are rendered. If a .atom request comes in, the
ContentNegotiatingViewResolver will look for a view that matches the
application/atom+xml media type. The view resolver will look for a view
rendering content with media type text/html is an .html request comes in. <bean
class="org.springframework.web.servlet.view.ContentNegotiatingViewResolver">
