asynchronous customization hooks have many caveats and it is uncertain if their

customization hooks via module.registerHooks() instead to avoid these caveats.
Asynchronous hooks run on a separate thread, so the hook functions cannot
directly mutate the global state of the modules being customized. It's typical
to use message channels and atomics to pass data between the two or to affect
control flows. See Communication with asynchronous module customization hooks .

require functions created using module.createRequire() are not affected. If the
